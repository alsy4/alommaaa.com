This is a sample project, used to smoke-test the association between
projects and blog posts: a project can have multiple posts, and a post
can optionally reference any number of projects it belongs to.

The "Hello, World" post is linked to this project (and another one) to
verify that both directions of navigation — project to posts, and post
back to its projects — resolve correctly at build time.
